# Star-Forge v0.1 — Playable prototype

## Included

- C17 fixed-capacity simulation for ships, projectiles, and cargo drops.
- SDL3 desktop frontend with a 320×180 logical render target.
- Player steering, thrust, reverse thrust, and forward weapon.
- Cargo, pirate, and patrol NPC role identifiers; starter scenario spawns a cargo hauler and pirate.
- Pirate pursuit and firing; cargo hauler travel toward the station.
- NPC ship destruction, physical cargo drops, and chance-based weapon salvage.
- Player collection, quantity-based cargo jettison, and station selling.
- Optional NPC salvage collection, toggled with F3.
- Fixed-step simulation update.

## Not included yet

Android Gradle/NDK packaging and APK validation; final sprites and animation; touch controls; save/load; missions; FTL; multiple systems; dynamic economy; advanced NPC navigation; factions and reputation; ship fitting and weapon fusion.

## Build

Requires a C17 compiler, CMake 3.21+, Git, and network access on first configure if SDL3 is not installed.

    cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build --config Release
    ctest --test-dir build --output-on-failure

Run the resulting star_forge executable.

## Simulation test without SDL

    cc -std=c17 -Wall -Wextra -Wpedantic -Isrc src/game.c tests/test_game.c -lm -o test_game
    ./test_game

See [controls](controls.md).
