# Godot v0.1 Playable Foundation

## Included
- Godot 4.7.2 project and typed GDScript runtime.
- Landscape Android configuration and Compatibility renderer.
- Touch joystick, BOOST and FIRE controls.
- Player ship movement, hull, armour, energy and weapon cooldown.
- Projectile collision and damage.
- Cargo hauler, pirate and patrol NPC foundations with data-driven ship designs.
- Asteroid and planetary collision bodies.
- Cargo drops, cargo capacity, collection and station selling.
- Four star systems with adjacency-based FTL and a 5-fuel cost.
- Local versioned save data and emergency recovery.

## Still in development
- Full persistence of every NPC and world object between system visits.
- Complete planet/moon landing and interaction mechanics.
- Dynamic economy, ship fitting, missions, factions, progression and additional NPC roles.
- Physical-device touch, lifecycle, performance and low-memory validation.

## Run
Open the repository root in Godot 4.7.2 and run `scenes/main.tscn`.

## Automated checks
Run the headless validation workflow in GitHub Actions. Android APK generation is performed by the separate cloud export workflow.
