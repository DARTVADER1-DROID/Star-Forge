# Star-Forge v0.1 controls

| Input | Action |
|---|---|
| W / Up | Accelerate |
| S / Down | Reverse thrust |
| A / Left | Turn left |
| D / Right | Turn right |
| Space | Fire forward |
| 1–5 | Select metal, fuel, food, medicine, weapon |
| + / - | Change jettison quantity |
| J | Jettison selected commodity quantity |
| E | Collect nearest cargo module |
| T | Sell selected inventory item at the station |
| I | Toggle cargo panel |
| F3 | Toggle NPC cargo collection |
| Escape | Quit |

Hover the mouse over a floating module to inspect its item and quantity. The first prototype has a 100-unit cargo limit and fixed local prices.

## Scenario

A cargo hauler starts with fuel, food, and metal. A pirate pursues and attacks it. Destroyed ships release their carried goods as physical modules and may drop a weapon. The player can attack ships, collect salvage, jettison low-value cargo, and sell goods at the station.

NPC salvage is enabled by default. When enabled, nearby NPCs can collect floating modules if they have cargo room. F3 disables NPC collection without disabling piracy or combat.
