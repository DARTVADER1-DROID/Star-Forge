# Game Assets

Runtime and source artwork for the Godot project.

- `ships/` — spacecraft sprites
- `weapons/` — weapon and turret sprites
- `projectiles/` — projectile art
- `effects/` — explosions, thrusters and impacts
- `asteroids/` — asteroid sprites
- `stations/` — stations and structures
- `backgrounds/` — space backgrounds and parallax layers
- `ui/` — interface graphics
- `audio/` — sound effects and music
- `fonts/` — bitmap or licensed fonts

See [Godot asset pipeline](../docs/asset-pipeline.md).
