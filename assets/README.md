# Assets

Place runtime-ready game assets here.

- `ships/` — spacecraft sprites
- `weapons/` — turret and weapon sprites
- `projectiles/` — projectile sprites
- `effects/` — explosions, thrusters, impacts
- `asteroids/` — asteroid sprites
- `stations/` — stations and structures
- `backgrounds/` — space backgrounds and parallax layers
- `ui/` — interface graphics
- `audio/` — sound effects and music
- `fonts/` — bitmap or other licensed fonts

Export sprites as transparent PNGs where appropriate. Keep editable Pixelorama/Aseprite source files when possible. See [the asset pipeline](../docs/asset-pipeline.md) for coordinate conventions and metadata examples.
